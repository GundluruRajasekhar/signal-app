# Signal — AI Task Intelligence

A single-file, zero-backend productivity app: an AI-parsed task board
plus a one-click AI-generated status briefing you can hand straight to
management. No build step, no server — open `index.html` or deploy it
as a static site.

- **App:** `index.html` (everything — HTML, CSS, JS — in one file)
- **Requirements:** `REQUIREMENTS.md`
- **Roadmap / task tracking for this project itself:** `TASKS.md`

## Run it locally

Just open `index.html` in a browser. To use the AI features (task
parsing + briefing generation), paste an Anthropic API key into
Settings — it's stored only in your browser's `localStorage` and used
to call `api.anthropic.com` directly from the page.
